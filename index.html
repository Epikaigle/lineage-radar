Comment le classement fonctionne

Les noms viennent des données officielles LineageOS. Les alias commerciaux partageant le même codename sont regroupés, ce qui permet à un modèle d’apparaître dans plusieurs gammes, par exemple Redmi et POCO. Le classement par défaut utilise la date de la dernière build disponible ; l’état « maintenu » correspond aux appareils présents dans les build targets officiels de LineageOS. Un appareil peut donc encore avoir des builds officielles téléchargeables tout en n’étant plus dans le roster actuel.
